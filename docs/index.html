bbmonitor

Clean, production-ready Bug Bounty scope monitor written in Go.

Go SQLite TUI + Daemon Telegram / Webhook MIT

What it does

  • Concurrently fetches public BB / VDP scopes from multiple trusted sources
  • Stores everything in SQLite + exports clean JSON
  • Detects every change (new program, scope add/remove/update…)
  • Notifies via Telegram or any webhook
  • Runs as interactive TUI or background systemd service
  • Single binary, resume-safe, config via YAML + environment variables

Quick start

go build -o bbmonitor ./cmd/bbmonitor
cp config.example.yaml config.yaml
./bbmonitor -once          # one-shot
./bbmonitor                # TUI
BB_MODE=daemon ./bbmonitor # background
